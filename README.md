# Number Guessing Game – DSA Assignment

## Description
A simple C++ console program that implements a number guessing game.
The program has a pre-chosen number (7) and asks the user to guess it.
After each guess, it tells the user if their guess was too high, too low,
or correct. Once the correct number is guessed, it displays the full 
history of all attempts made.

## Concepts Used
- Variables
- While loop
- If/else statements
- Arrays (vectors)
- For loop

## How to Run
1. Open the file in any C++ compiler
2. Run the program
3. Enter numbers when prompted until you guess correctly
